# 三角形部队 Triangle Squad

一个给小朋友玩的 3D 网页游戏：指挥一支闪闪发光的三角形部队，招募士兵、升级能力，打败方块怪兽军团和暗黑魔方王！

还有 **学习模式**：打开后，出发、过关、升级、复活前都要先背英语单词、答对题目才能继续。学习模式可以在开始界面或暂停菜单里随时关掉。

## 怎么玩

不用安装任何东西：

1. 下载这个仓库（GitHub 页面上点绿色的 **Code → Download ZIP**，然后解压）。
2. 双击打开 `index.html`，用 Chrome、Edge 或 Safari 都可以。

| 操作 | 电脑 | 平板 / 手机 |
| --- | --- | --- |
| 移动 | WASD 或方向键 | 手指在屏幕上拖动 |
| 射击 | 自动，靠近怪兽就会开火 | 同左 |
| 超级冲击波 | 空格键 | 点底部的 ⚡ 按钮 |
| 暂停 | P 或 Esc | 点右上角 ⏸ |

- 碰到 **绿色三角形** 就能把它招进部队。部队越大，火力越猛。
- 打怪会掉 **黄色水晶**，攒满经验条就能升级，从 3 个新能力里选一个。
- 每 5 波会出现 **大王**。

## 学习模式

- 一共 150 个适合 8 岁左右孩子的常用单词（动物、颜色、数字、食物、身体、家人、交通、学校、自然……），每个都配了图标和中文意思。
- **背单词**：每次出发前先看 2 个新单词卡片（大王关前是 3 个），会自动用英语读出来。
- **小测验**：题型有看图选英文、看英文选中文、听音选单词、补全缺的字母。答错的单词会让孩子重新背一遍再考。
- **升级** 前答对 1 题，**复活** 要答对 2 题（每局最多复活 2 次，只有学习模式下才能复活）。
- **单词本**：开始界面点「📖 单词本」，能看到学过的单词和已掌握的单词（⭐），点一下就能听发音。
- 学习进度保存在浏览器里，下次打开还在。

## 文件说明

- `index.html`：游戏页面
- `js/game.js`：3D 场景和游戏玩法
- `js/learn.js`：学习模式（单词卡片、测验、单词本）
- `js/words.js`：单词表，想加单词或换单词，直接改这里
- `js/audio.js`：音效和背景音乐（都是实时合成的，不需要音频文件）
- `lib/three.min.js`：Three.js r159（MIT 许可），放在本地，没网也能玩
