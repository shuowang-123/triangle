# 三角形部队 Triangle Squad

一个给小朋友玩的 3D **第一人称射击** 网页游戏：拿着三角形激光枪、带上手榴弹，和你的三角形队友一起打败方块坏蛋军团和方块大魔王！坏蛋被打中只会变成一堆方块碎片，不血腥。

还有 **学习模式**：打开后，出发、升级、复活前都要先背英语单词、答对题目才能继续。学习模式可以在开始界面或暂停菜单里随时关掉。

## 怎么玩

在线直接玩：https://shuowang-123.github.io/triangle/

也可以下载这个仓库，双击打开 `index.html`。

| 操作 | 电脑 | 平板 / 手机 |
| --- | --- | --- |
| 移动 | WASD 或方向键 | 左下角摇杆 |
| 瞄准 | 移动鼠标（先点一下屏幕） | 右半边屏幕拖动 |
| 开枪 | 按住鼠标左键 | 按住 🔥 |
| 手榴弹 | 右键 或 G | 点 💣 |
| 跳 | 空格（可以跳上箱子） | 点 ⬆ |
| 暂停 | Esc 或 P | 点右上角 ⏸ |

- 打中坏蛋的头算 **爆头**，伤害和分数都翻倍。
- 碰到 **绿色三角形**，它就会变成你的队友，跟在你身后一起开枪。
- 坏蛋会掉 **黄色水晶**（经验）、💣 手榴弹箱、❤️ 回血。攒满经验就升级，从 3 个新能力里选一个。
- 右上角雷达能看到坏蛋（红点）在哪。
- 每 5 波出现 **方块大魔王**，它会放一圈能量弹，跳起来就能躲开。

## 学习模式

- 一共 150 个适合 8 岁左右孩子的常用单词（动物、颜色、数字、食物、身体、家人、交通、学校、自然……），每个都配了图标和中文意思。
- **背单词**：每次出发前先看 2 个新单词卡片（大王关前是 3 个），会自动用英语读出来。
- **小测验**：题型有看图选英文、看英文选中文、听音选单词、补全缺的字母。答错的单词会让孩子重新背一遍再考。
- **升级** 前答对 1 题，**复活** 要答对 2 题（每局最多复活 2 次，只有学习模式下才能复活）。
- **单词本**：开始界面点「📖 单词本」，能看到学过的单词和已掌握的单词（⭐），点一下就能听发音。
- 学习进度保存在浏览器里，下次打开还在。

## 文件说明

- `index.html`：游戏页面
- `js/game.js`：3D 场景、第一人称射击玩法、坏蛋和队友
- `js/learn.js`：学习模式（单词卡片、测验、单词本）
- `js/words.js`：单词表，想加单词或换单词，直接改这里
- `js/audio.js`：音效和背景音乐（都是实时合成的，不需要音频文件）
- `lib/three.min.js`：Three.js r159（MIT 许可），放在本地，没网也能玩
